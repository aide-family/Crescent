## 关键限制和用户控制

- 代码索引仅在本机运行；不会上传整个项目。Agent 查询结果/明确 read 的片段会作为当前对话工具输出发送给所选模型，与现有工具语义一致。
- 按用户后续“调整”要求，历史整理使用当前聊天栏选定的已启用模型，支持远程服务。首次远程整理先显示服务地址、模型与发送内容说明并请求授权；授权绑定 provider ID、model ID、规范化完整 base URL。模型/地址改变时需重新确认，可一键撤销全部远程整理授权并取消在途任务。授权持久化在 memory.db，未授权时主进程拒绝网络请求。
- 请求前脱敏，但主机名、架构和操作内容仍可能包含内部信息，确认界面明确说明。请求只允许所选 origin，拒绝重定向；不静默回退到其他模型。本机 localhost/127.0.0.1/[::1] 不需远程授权。手动及批量整理绑定当前聊天模型；开启自动整理时保存所选模型，后台同样校验授权。
- 可关闭自动整理，即使模型未配置或远程授权已撤销；既有自动整理开关不会绕过主进程的发送授权检查。截图中的 Electron IPC 报错前缀在 UI 中转换为用户提示。

- 召回知识是历史资料，不是当前生产事实，也不授权任何命令。候选/已归档条目不会新增召回；删除或关闭召回不会撤回已经发送给模型的内容，它仍可能保留在当前会话上下文中。SSH 知识按 connection ID 隔离；只有空范围偏好跨连接共享。
- 索引拒绝敏感路径、符号链接、特殊文件、依赖目录和构建产物，正文脱敏后持久化。每项目最多 2000 个代码文件、20000 次目录项访问、24 层目录，预算统计正文及解析结果；单文件最多约 512 KiB/10000 行。到上限会显示有限索引；取消保留原完整缓存。
- 图谱是静态导入关系和词法证据，无法证明动态调用、Python 包解析、任意 TS alias 或 Electron IPC 的实际运行链。需要用 read 核对两端；查询返回 caveat。
- 记忆中心列出最近 200 次历史；单会话最多 2000 条消息/12 万字符，超过上限拒绝完成标记。分段请求每段最多 60 秒，可取消。知识上限 2000 条、每条内容最多 12000 字符；问题召回内容总预算约 10000 字符。
- 自动整理默认关闭，不自动确认；后台失败通过中心展示，失败修订在当前进程中不反复重试。可手动重试或关闭再开启自动整理。
- 删除历史不会删除已确认知识；保留来源 ID 和复核时间，来源已删除时入口明确提示。清空记忆清理知识、关系和学习标记，保留原对话与控制设置。
