# Crescent 数字员工能力实施计划

来源：用户指定的 ChatGPT「数字员工计划」（2026-10-11）。本文将该计划落实为当前工作区的工程范围；实现和验收结果见 [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md)。

## 目标与边界

在现有 Pi 1.0.3 Host 架构内新增代码理解和长期运维知识。保留原有 `read`，先用索引定位，再读取当前源码核对。保持 main → typed preload → renderer 边界，renderer 不读取文件或数据库。不开启 Pi 项目 extensions，不替换 SDK，不训练模型，不进行云同步，不自动执行运维命令或修改代码。本次只开发、测试和构建，不执行 electron-builder、不制作安装包。

## 数据和工具

代码索引包含项目根目录、文件路径、语言、脱敏内容哈希、符号位置、词法引用和静态导入边。由 main 维护 `code_index.db`，依赖图不把同名符号视为确定身份，不推断未验证的 Electron IPC 或动态调用。

新增 Host 工具：`code_search`、`symbol_lookup`、`dependency_trace`、`impact_analysis`、`memory_search`。所有工具有受限参数与输出并加入 Pi allowlist/catalog。索引范围是本地客户端工作目录，SSH 会话不改变文件访问目标。

长期知识包括 title/content/category/source/scope/confidence/status/createdAt/updatedAt。类别为 environment/architecture/operation/troubleshooting/preference；状态为 candidate/approved/archived。简单关系保存在 memory_relation。学习记录保存来源修订和去重后的知识关联。

## UI 和数据流

顶部新增记忆中心按钮，保留历史、本地资料等入口。中心提供数量、分类/状态/关键词筛选、手动新增、审核编辑、来源会话、关系编辑、删除和清空确认。历史页显示待整理/有新内容/待审核/已学习/已归档，可逐条或批量整理、取消。

设置页面新增 Code Intelligence：根目录授权、状态、重新索引、取消、删除缓存，以及搜索/符号/依赖/影响查询。选定额外目录仅授权本次窗口；Agent 工具仍绑定配置中的工作目录。

历史 → 独立无工具所选模型请求 → 校验和脱敏 → 候选知识 → 人工审核 → 已确认知识 → 按问题和连接范围召回。偏好可以设置为空范围并跨连接召回；其他空范围知识只在本地会话使用。

## 隐私决策

根据用户后续“调整”要求，历史整理改为使用当前聊天选定的模型，支持本机与远程服务。首次向远程目标发送前，在记忆中心显示服务地址、模型、发送内容说明并明确授权；授权绑定 provider/model/规范化服务地址，可撤销。发送前脱敏，请求限定所选 origin 并拒绝 HTTP 重定向，不回退到其他模型。

已确认知识用于回答时会随当前请求发给用户当前选定的模型，中心明确显示这一点，并提供召回关闭开关。历史整理与自动整理向远程模型发送时均需相同的目标授权。自动整理默认关闭，即使启用也仅产生候选，不自动批准。

## 验证与交付

运行 `npm run ci` 和 `npm run test:local`，补充真实 SQLite/Tree-sitter 测试及隔离 Electron 运行检查。单元测试留在本机并保持 gitignored，不提交测试文件。使用独立 CRESCENT_DATA_DIR/CRESCENT_USER_DATA_DIR，不触碰用户原有配置、连接和历史。

原计划提出分阶段提交，但当前工作区已有大量未提交且相互依赖的修改；本轮保留这些修改，不混入提交。实施和验收记录明确区分本地源代码、运行检查、模型提炼质量和 Git/安装包交付。
