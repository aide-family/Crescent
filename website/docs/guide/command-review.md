# 命令审核

AI 生成的命令在执行前会经过独立审核。审核说明：

- 为什么要执行这条命令
- 是否会改变系统、集群、文件、网络、服务、凭据或数据状态
- 风险等级
- 是否需要你确认
- 可能的影响和建议

只读、意图清楚的检查可以自动放行。会改变状态或含义含糊的命令必须确认后才执行。

需要人工确认的典型情况包括删除文件、重启服务、提权、写文件和修改配置。AI 用来加快检查，不绕过判断。

审核发生在命令进入终端之前。你仍然可以在可见终端里看到最终执行的内容和输出。

## 风险等级

| 等级 | 通常怎么处理 |
| --- | --- |
| 低 | 只读、意图清楚的检查可以自动放行。多条只读命令会折叠显示 |
| 中 | 影响有限或含义不够清楚时，等你确认 |
| 高 | 删除、重启、提权、写文件、改配置等会改变状态的操作，必须你批准后才写入终端 |

批准或拒绝时可以写备注，例如只允许只读、范围不对、注意目标路径。会话已经关闭时，尚未执行的审批会自动取消。

## 命令白名单

设置里的命令白名单让你信任的命令跳过这次 AI 风险审核，直接执行。一行一条规则：

- 普通文本：整条命令精确匹配
- 末尾 `*`：前缀匹配
- `/.../`：按正则匹配

审核卡片里也可以把当前命令加入白名单。白名单省掉的是重复确认，不是终端上的可见性：命令仍然在当前面板里执行，输出仍然看得到。
