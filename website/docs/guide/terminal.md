# 终端与 Agent

Crescent 内置本地终端，支持 PTY。Agent 在**当前可见终端**里执行命令并读取真实输出，终端不是旁边一块只用来粘贴命令的黑框。

这意味着：

- 你能看到正在跑的命令和输出。
- Agent 的下一步基于这次输出，而不是假设环境长什么样。
- 需要另一台机器或另一个上下文时，用 `open_subterminal` 停靠一个专用子终端，而不是把所有命令混在同一个会话里。

## 适合的任务

- 本机磁盘、内存、服务状态巡检
- 部署前检查
- 根据上一条命令的失败输出继续缩小范围

跨主机工作时，先在 [SSH 连接](/guide/ssh) 里选中目标，再让 Agent 基于那条连接继续检查。
