# 工作台

Crescent 把对话和终端放在同一个窗口里。布局和说话方式可以按你的习惯改，安全规则不会跟着变松。

## 布局

设置里的工作台布局会立刻生效，并在下次打开时沿用：

| 布局 | 看到什么 |
| --- | --- |
| 对话和终端 | 左右同时保留对话与终端，默认工作方式 |
| 仅对话 | 收起终端，适合先把目标和结论说清楚 |
| 仅终端 | 收起对话，适合你自己看命令输出 |

顶栏也可以交换对话和终端的左右位置。关闭终端 Tab 前可以要求再次确认，避免误停正在用的会话。

## 工作风格

工作风格只控制 Crescent 对你说多少。它不会少做检查，也不会跳过 [命令审核](/guide/command-review)。

| 风格 | 适合 |
| --- | --- |
| 极速 | 过程尽量静默，结束时 1–3 句结论。适合自己盯着终端的熟手 |
| 简洁 | 阶段最多一句状态，最后给短结论。适合值班 |
| 协作 | 结对排查：说明目标、证据和下一步 |
| 详解 | 解释为什么查、证据意味着什么。适合学习 |

「显示思考过程」可以覆盖风格默认值。极速、简洁、协作默认隐藏思考；详解默认展开。

系统日志写入 `~/.crescent/logs`，按天分割并保留 3 天。默认级别是 info，也可以关掉或调到 debug。
