# 快速开始

1. 按 [安装](/guide/install) 打开 Crescent。
2. 配置一个 OpenAI 兼容的模型供应商，并选择模型。
3. 在终端旁边直接描述要做的检查。

例如，检查当前机器：

```text
检查当前机器的磁盘、内存、系统服务状态，并给出异常项和建议。
```

或者，针对已配置的远程环境：

```text
连接 production，检查 Kubernetes 集群里异常 Pod，并整理一份排障结论。
```

Agent 会查看当前终端上下文，执行必要命令，阅读输出，再决定继续检查、修复，还是总结。高风险命令会先进入 [命令审核](/guide/command-review)。

## 一次闭环里会发生什么

1. 理解你的目标。
2. 查看当前终端在哪台机器、哪个目录。
3. 执行一条有用的命令。
4. 分析输出。
5. 继续检查、应用修复，或给出结论。

只读巡检、部署前检查和排障都适合这种节奏。不要指望一次生成整段无人看管的脚本。
